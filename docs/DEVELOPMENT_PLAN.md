# Word AI 创作助手 - 开发文档与演进计划 (Development Plan)

> 本文档详细记录了 Word AI 创作助手（Word AI Copilot Add-in）的系统设计、已实现的核心功能里程碑以及后续版本的进阶开发储备计划。

---

## 📖 项目定位与技术栈

- **平台规范**：Microsoft Office 官方现代 Web Add-in 规范、Word.js JavaScript API
- **前端架构**：原生 HTML5 / CSS3 (微软 Fluent 2.0 规范) / 原生 Vanilla JavaScript
- **部署架构**：静态资源托管于 GitHub Pages / Cloudflare Pages（自带权威合法 SSL 证书）
- **大模型生态**：全兼容 OpenAI 标准接口协议（支持 DeepSeek、OpenAI、SiliconFlow、Moonshot 及本地 Ollama、vLLM、LocalAI）

---

## 🏆 已完成里程碑 (Completed Milestones)

### 阶段一：精准审阅定稿闭环与公文规范排版工具箱
1. **微观逐处复核与全局一键定稿**：
   - 自动解析行内/段落级差异（`<del>` 删除线与 `<ins>` 下划线）；
   - 联动在 Word 正文中高亮滚动定位当前处；
   - 支持单处 `[采纳本处]` 或 `[保留原句]`；
   - 支持全局 `[全部采纳定稿]`（消除标记正式成文）与 `[全部撤销恢复]`。
2. **直接打字注文与光标定位**：
   - 边思考边将 AI 文字直接注入 Word 正文（无额外文本框干扰）；
   - 生成完毕或手动停止后，Word 光标自动精准吸附于注入文字的段尾，便于立即接续创作。
3. **独立公文规范排版工具箱**：
   - 严格仅对划选文字生效，未划选时主动拦截并温和提示；
   - 包含：大标题（方正小标宋二号居中）、一级标题（黑体三号缩进）、二级标题（楷体三号加粗）、三级标题（仿宋三号加粗）、公文正文（仿宋三号固定28磅）与一键格式清洗。

### 阶段二：全文智能校对体检看板与长文大纲提要提炼
1. **全文智能校对体检看板与黄色高亮自动修复**：
   - AI 全方位审阅错别字、语病、标点规范、术语统一与公文逻辑；
   - **`🟡 黄色高亮全文疑点`**：在 Word 原文将所有检出疑点打上黄色背景高亮，一目了然；
   - **`⚡ 一键自动修复全部`**：一键批量替换所有错误词句为建议值，并自动清除黄色高亮；
   - **`🧹 清除全文高亮`**：随时一键擦除正文中的黄色标记；
   - 逐条导航卡片展示原句、建议与原因，支持单条定位、采纳与忽略。
2. **长文大纲与提要提炼**：
   - **`🏗️ 一键插入 Word 骨架`**：解析分级标题，在当前位置自动生成规范层级的标题骨架并套用黑体/楷体/仿宋样式；
   - **`📋 复制为思维导图/MD`**：一键复制树形结构文本，可直接粘贴导入 XMind / 幕布 / 飞书思维导图；
   - **`📌 一键插入文档提要`**：自动在文档最开端插入带格式的【内容提要】引言段落。

### 阶段三：专属金句语料库素材抽屉与标杆文风模仿
1. **专属金句语料库抽屉**：
   - 内置高质量素材库：体制公文对仗、学术论述经典、商业汇报精粹；
   - **Word 选区一键导入**：选中的精美词句一秒收藏进个人本地语料库；
   - 快速交互：一键插入当前光标处、一键引用到自定义 Prompt 指令框、一键复制。
2. **标杆文风模仿（Style Mimicry）**：
   - 支持从 Word 选区采纳或手动粘贴高水平标杆范文；
   - 智能提炼文风特征标签（如：对仗工整、站位高远、层层递进、严谨精炼）；
   - 快捷处理卡片一键开关「文风模仿」，后续全流程生成自动深度克隆其文风节奏与韵味。

## 🔮 待实施储备计划 (Future Development Plan)

### 阶段四：🏛️ 公文与严肃政务写作深度赋能（高优先级）
1. **公文政治表述与敏感规矩合规排查（政务安全哨兵）**
   - **功能**：自动扫描重大会议提法、权威政治表述是否规范；排查多位领导姓名职务排序合规性；敏感旧称、不合规缩写自动预警。
   - **交互**：在 Word 正文中以橙红色波浪线高亮标出，提供一键纠偏。
2. **公文小标题对仗工整化生成器（排比对仗神器）**
   - **功能**：划选粗糙标题或输入核心要旨，一键生成 3~5 组字数一致、词性相对、动宾对仗的标题组，解决“想破头”难题。
3. **目标字数精准弹性伸缩（篇幅精准裁剪）**
   - **功能**：滑动设置或直接输入目标字数（如“压缩到 600 字”、“扩充至 1500 字”），AI 在保留核心论点的前提下精准增删。

### 阶段五：🎓 学术论文与专业排版深化
4. **学术文献引用标准化（GB/T 7714-2015 与 APA 格式化）**
   - **功能**：划选期刊标题、网页或 DOI，一键转换为标准 GB/T 7714 参考文献条目；正文光标处插入 `[1]` 上标，文末参考文献列表同步追加。
5. **中英双语逐段对照排版（涉外合同/论文摘要）**
   - **功能**：支持「中英文隔段对照写回」与「中英文双列表格写回」。
6. **Word 原生学术三线表插入**
   - **功能**：直接生成顶线 1.5 磅、底线 1.5 磅、栏目线 0.75 磅的标准期刊三线表。
7. **全文档一键隐私脱敏与保护**
   - **功能**：对外公开发布前，一键将电话（`138****0000`）、身份证号、姓名与金额脱敏处理。

### 阶段六：💬 交互升级与多模态赋能
8. **与当前长文档深度问答检索（Chat with Document）**
   - **功能**：侧边栏专属问答面板，针对长文内容自由提问验证细节，附带原文段落定位跳转。
9. **语音口述速记与实时书面化润色（Voice to Doc）**
   - **功能**：直接口述录音，AI 自动过滤口头语并实时整理为严谨规范的书面语直接写入 Word。
