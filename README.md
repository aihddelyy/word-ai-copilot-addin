# Word AI 创作助手 (Word & WPS AI Copilot Add-in)

> 基于微软现代官方 **Office Web Add-in (Word.js)** 与 **WPS JS-Addin (JSA)** 双标准架构构建的高性能专业级 AI 创作助手插件。
> 支持 **Microsoft Word** 与 **WPS 文字** 双办公平台，支持 **GitHub Pages 官方线路** 与 **Cloudflare Pages 全球加速线路** 智能双轨测速与自动容灾，真正做到**开箱即用，无需配置本地证书或启动本地服务**！

---

## ✨ 核心特性

### 1. ⚡ 统一安装，智能双轨测速与容灾
- **双办公平台统一安装**：运行 `install.bat`，可交互选择安装至 **Microsoft Word**、**WPS 文字** 或 **两者兼装**。
- **双线路智能优选**：支持 **GitHub Pages 官方线路** 与 **Cloudflare Pages (`word-ai-copilot-addin.pages.dev`)** 双线路容灾。
- **自动极速测速**：安装脚本自动进行 2.5 秒极速测速探测，优先选用 GitHub Pages；若连接不畅或超时，**秒级自动无缝切换至 Cloudflare Pages 全球加速线路**！
- **命令行传参支持**：
  - `install.bat`：交互式选择软件，自动测速优选线路（推荐）；
  - `install.bat word`：直接安装到 Microsoft Word；
  - `install.bat wps`：直接安装到 WPS 文字；
  - `install.bat all`：一键同时配置 Word 与 WPS；
  - `install.bat all cf`：强制指定选用 Cloudflare 全球加速线路；
  - `install.bat all gh`：强制指定选用 GitHub Pages 官方线路。

### 2. 📚 深度专精的写作提示词库与公文对仗
内置 10 种涵盖体制内公文、学术科研、职场汇报等高频核心场景的专用 Prompt：
1. **公文结构改写**：严格遵循体制内公文规范，讲政治、站位高、层次严谨、标题工整对仗（一、（一）1. 规范）。
2. **论文降重与改写**：重构学术句式语态、同义词深度替换、拆分长难句，消除查重痕迹同时保持原意。
3. **整理对比三线表**：提炼关键指标，转化为规范的标准 Markdown 学术/公文三线对比表格。
4. **核心要点加粗**：梳理逻辑要点列表，自动对专业术语、关键数据、结论进行 `**加粗**` 突出显示。
5. **消除套话与口语**：剔除冗余修饰词、套话、废话及口头语，使行文紧凑利落、字字珠玑。
6. **会议纪要待办化**：将零散发言整理为“会议共识、决议事项、分工待办清单”三位一体规范纪要。
7. **领导致辞起草**：起草热情洋溢、高屋建瓴、催人奋进的讲话稿与致辞。
8. **SCI 论文学术润色**：英文学术母语级润色，符合 Nature、IEEE 等国际权威顶刊规范。
9. **金字塔逻辑汇报**：麦肯锡金字塔原理，结论先行、以上统下、归类分组、逻辑递进。
10. **法律免责与合规条款**：自动补充严密的商业合规边界提示与法律免责声明。

### 3. 🎛️ 提示词自定义、就地编辑与快捷展示开关
- **自由再次编辑**：收藏库中的任意提示词均支持点击“编辑”就地修改标题、详细要求与快捷展示状态，保存即刻生效。
- **快捷显示控制**：在“Prompt 收藏库”抽屉中自由决定是否在主界面的自定义指令输入框下方展示快捷胶囊。
- **导入与导出**：一键导出为标准 JSON 文件，或从 JSON 文件批量导入，轻松实现跨设备备份与团队共享。

### 4. 🤖 现代模型选择器与动态拉取
- 针对 Word 与 WPS 内嵌 WebView2 环境进行专门优化，彻底根除原生下拉列表点击闪退、失焦关闭的问题。
- **获取/刷新模型**：填入 API Key 与 Base URL 后，点击即可一键动态拉取服务商支持的全部模型清单。
- **手动输入切换**：遇到私有部署或未在列表列出的特殊模型，可一键切换为手动输入模式。

### 5. 🌐 多模型通用兼容生态
完全兼容 OpenAI 接口规范，支持无缝切换国内外主流大语言模型：
- **DeepSeek**（官方 API，高性价比推荐）
- **OpenAI**（GPT-4o / GPT-4o-mini / o1 / o3-mini 等）
- **硅基流动 (SiliconFlow)**（极速全托管）
- **月之暗面 (Moonshot / Kimi)**
- **本地 Ollama / vLLM / LocalAI**（内网离线隐私场景）

### 6. 🏛️ 独立公文规范排版工具箱
内置严格符合国家标准与体制内规范的一键排版系统（Word 与 WPS 通用支持）：
- **大标题**：二号、方正小标宋简体、自动居中、单倍行距、无首行缩进。
- **一级标题**：三号、黑体（不加粗）、首行缩进 2 字符、固定值 28 磅行距。
- **二级标题**：三号、楷体_GB2312、加粗、首行缩进 2 字符、固定值 28 磅行距。
- **三级标题**：三号、仿宋_GB2312、加粗、首行缩进 2 字符、固定值 28 磅行距。
- **公文正文**：三号、仿宋_GB2312、首行缩进 2 字符、固定值 28 磅行距、两端对齐。
- **格式清洗**：一键去除网页/微信复制带来的异常底色、多余格式与修饰。

### 7. ✍️ 灵活精准的文档写回与审阅定稿闭环
- **选区自动感知**：选中文本实时同步至面板，显示字数统计与即时预览。
- **直接注文**：像打字机一样直接边思考边打字注入正文。
- **替换选中（保留格式）**：按富文本格式替换（保留加粗、标题、列表、表格并继承原正文字体）。
- **审阅红线 (逐字划线)**：模拟 Word 审阅修订，红色删除线标出原字句，绿色下划线标出新增字词，**纯划线处理，无突兀底色**。
- **段落对照 (逐段对照)**：专为大篇幅改写设计，一段对一段输出（原段落整段红色划线，新段落整段绿色文字）。
- **🎯 审阅定稿控制台**：
  - 微观逐处复核：`[上一处]` `[下一处]` 联动定位，单独 `[采纳本处]` 或 `[保留原句]`。
  - 全局一键定稿：`[全部采纳定稿]` 或 `[全部撤销恢复]`。

## 🚀 极速安装与使用

### 方案 A：Windows PowerShell 一键在线安装（推荐，免装 Git，极速直连 ⚡）

无需克隆或下载完整仓库，只需按下键盘上的 `Win + X`（或在开始菜单搜索并打开 **Windows PowerShell**），直接复制并粘贴运行以下命令之一：

**GitHub 镜像加速源（国内直连推荐）：**
```powershell
irm https://ghfast.top/https://raw.githubusercontent.com/aihddelyy/word-ai-copilot-addin/main/online-install.ps1 | iex
```

**Cloudflare Pages 全球 CDN 加速源（备用）：**
```powershell
irm https://word-ai-copilot-addin.pages.dev/online-install.ps1 | iex
```

> **说明**：脚本将自动探测最快的加速节点，高速下载轻量核心配置并弹出软件选择菜单（直接回车默认安装到 Word + WPS），数秒内全自动搞定！

---

### 方案 B：本地下载一键安装

1. 克隆或下载本项目到本地电脑任意文件夹：
   ```bash
   git clone https://github.com/aihddelyy/word-ai-copilot-addin.git
   ```
2. 双击运行根目录下的 **`install.bat`**。
3. 按照控制台提示输入选项（直接按回车默认安装到 Word 和 WPS 两者）：
   ```text
   请选择要安装的目标办公软件：
     [1] Microsoft Word (Office 365 / 2021 / 2019 / 2016)
     [2] WPS 文字 (WPS Office / 个人版 / 专业版 / 信创版)
     [3] 同时安装到 Word 和 WPS 两者 (推荐)
     [0] 退出
   ```
4. 脚本将全自动完成网络测速、动态配置与注册！

---

### 方案 C：启动与使用
- **Microsoft Word**：启动 Word，在顶部 **【开始】** 选项卡最右侧即可看到 **【AI 创作助手】** 按钮组；
- **WPS 文字**：启动 WPS 文字，在顶部功能区会看到新增的专属 **【AI 创作助手】** 选项卡，点击大图标即可唤出侧边栏！

## 🗑️ 完全卸载

若需要完全清理本插件，只需双击根目录下的 **`uninstall.bat`**：
根据提示选择 `[1] 仅清理 Word`、`[2] 仅清理 WPS` 或 `[3] 完全清理两者`，一键还原所有配置与注册表，干净无残留。

---

## ⚙️ 模型配置与快速上手

1. 在 Word 或 WPS 侧边栏中点击右上角 **⚙️【设置】** 图标。
2. **选择服务商**（例如 **DeepSeek**，系统将自动填充 Base URL 与默认模型）。
3. **输入 API Key**（在对应平台申请的 Key，如 `sk-...`）。
4. （可选）点击 **【获取/刷新模型】** 按钮从服务端动态加载可用模型列表并选择。
5. 点击 **【测试 API 连通性】**，提示成功后点击 **【保存并应用】**。
