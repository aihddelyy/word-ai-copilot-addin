# Word AI 创作助手 (Word AI Copilot Add-in)

> 基于微软现代官方 **Office Web Add-in** 规范与 **Word.js API** 构建的高性能专业级 AI 创作助手插件。
> 现已接入 **GitHub Pages 云端公共 HTTPS 托管**，真正做到**开箱即用，无需配置本地证书或启动本地 Python 服务**！

---

## ✨ 核心特性

### 1. ⚡ 云端托管，零依赖一键安装
- 静态页面托管于 GitHub Pages，自带合法有效的权威 SSL 证书。
- Windows 桌面端 Word 用户**只需双击 `install-to-word.bat`** 即可全自动完成安装注册与缓存清理，开箱即用。

### 2. 📚 深度专精的 Word 写作提示词库
内置 10 种涵盖体制内公文、学术科研、职场汇报等高频核心场景的专用 Prompt：
1. **公文结构改写**：严格遵循体制内公文规范，讲政治、站位高、层次严谨、标题工整对仗（一、（一）1. 规范）。
2. **论文降重与改写**：重构学术句式语态、同义词深度替换、拆分长难句，消除查重痕迹同时保持原意。
3. **整理对比三线表**：提炼关键指标，转化为规范的标准 Markdown 学术/公文三线对比表格。
4. **核心要点加粗**：梳理逻辑要点列表，自动对专业术语、关键数据、结论进行 `**加粗**` 突出显示。
5. **消除套话与口语**：剔除冗余修饰词、套话、废话及口头语，使行文紧凑利落、字字珠玑。
6. **会议纪要待办化**：将零散发言整理为“会议共识、决议事项、分工待办清单”三位一体规范纪要。
7. **领导致辞起草**：起草热情洋溢、高屋建瓴、催人奋进的讲话稿与致辞。
8. **SCI 论文学术润色**：英文学术母语级润色，符合 Nature、IEEE 等国际权威顶刊规范。
9. **金字塔逻辑汇报**：麦肯锡金字塔原理，结论先行、以上统下、归类分组、逻辑递进。
10. **法律免责与合规条款**：自动补充严密的商业合规边界提示与法律免责声明。

### 3. 🎛️ 提示词自定义、就地编辑与快捷展示开关
- **自由再次编辑**：收藏库中的任意提示词均支持点击“编辑”就地修改标题、详细要求与快捷展示状态，保存即刻生效。
- **快捷显示控制**：在“Prompt 收藏库”抽屉中，每个提示词后均配备 **快捷显示勾选框**，自由决定是否在主界面的自定义指令输入框下方展示为一键点击填入的快捷胶囊。
- **自定义扩充与管理**：支持随时添加属于你个人的个性化 Prompt，删除带确认防误触。
- **导入与导出**：一键导出为标准 JSON 文件，或从 JSON 文件批量导入，轻松实现跨设备备份与团队共享。

### 4. 🤖 现代模型选择器与动态拉取
- 针对 Word 内嵌 WebView2 环境进行专门优化，彻底根除原生下拉列表点击闪退、失焦关闭的系统级问题。
- **获取/刷新模型**：填入 API Key 与 Base URL 后，点击即可一键动态拉取服务商支持的全部模型清单。
- **手动输入切换**：遇到私有部署或未在列表列出的特殊模型，可一键切换为手动输入模式。

### 5. 🌐 多模型通用兼容生态
完全兼容 OpenAI 接口规范，支持无缝切换国内外主流大语言模型：
- **DeepSeek**（官方 API，高性价比推荐）
- **OpenAI**（GPT-4o / GPT-4o-mini / o1 / o3-mini 等）
- **硅基流动 (SiliconFlow)**（极速全托管）
- **月之暗面 (Moonshot / Kimi)**
- **本地 Ollama / vLLM / LocalAI**（内网离线隐私场景）

### 6. 🏛️ 独立公文规范排版工具箱
内置严格符合国家标准与体制内规范的一键排版系统：
- **大标题**：二号、方正小标宋简体、自动居中、单倍行距、无首行缩进。
- **一级标题**：三号、黑体（不加粗）、首行缩进 2 字符、固定值 28 磅行距。
- **二级标题**：三号、楷体_GB2312、加粗、首行缩进 2 字符、固定值 28 磅行距。
- **三级标题**：三号、仿宋_GB2312、加粗、首行缩进 2 字符、固定值 28 磅行距。
- **公文正文**：三号、仿宋_GB2312、首行缩进 2 字符、固定值 28 磅行距、两端对齐。
- **格式清洗**：一键去除网页/微信复制带来的异常底色、多余格式与修饰。

### 7. ✍️ 灵活精准的文档写回与审阅定稿闭环
- **选区自动感知**：选中文本实时同步至面板，显示字数统计与即时预览。
- **替换选中（保留格式）**：按 Word 原生富文本格式替换（保留加粗、标题、列表、表格并继承原正文字体）。
- **审阅红线 (逐字划线)**：模拟 Word 审阅修订，红色删除线标出原字句，绿色下划线标出新增字词，**纯划线处理，无突兀底色**，清晰自然。
- **段落对照 (逐段对照)**：专为大篇幅改写设计，**一段对一段输出**（原段落整段红色划线，新段落整段绿色文字，无底色），告别字词交织混乱。
- **🎯 审阅定稿控制台**：
  - **微观逐处复核**：自动汇总修改点数，提供 `[上一处]` `[下一处]` 联动在 Word 正文中高亮滚动定位，并可单独 `[采纳本处]` 或 `[保留原句]`。
  - **全局一键定稿**：点击 `[全部采纳定稿]`，一键清除所有红色删除标记并将新文字转为正式正文交付；点击 `[全部撤销恢复]`，一秒还原最初原貌。
- **纯文本替换**：100% 继承 Word 原位置所有字体、字号与段落样式。
- **在后方追加**：在选中文本后另起新段落追加插入。
- **光标处插入**：直接输出到文档光标所在位置。
- **差异对比 (Diff)**：左右并排查看修改前后文字差异。
- **一键复制**：将生成结果快速复制至剪贴板。

### 8. 🔒 纯本地安全存储
- API Key 仅保存在本机宿主环境的 `localStorage` 沙箱中，绝不经由任何第三方中间服务器。

## 🚀 极速安装与使用

### 方案 A：Windows 桌面版 Word（推荐，一键安装 ⚡）

1. 克隆或下载本项目到本地电脑任意文件夹：
   ```bash
   git clone https://github.com/aihddelyy/word-ai-copilot-addin.git
   ```
2. 双击运行根目录下的 **`install-to-word.bat`**。
   > 脚本会自动关闭 Word、清理旧 WEF 缓存，并将插件注册至本机 Office 开发者加载项目录。
3. 打开 Microsoft Word。
4. 在顶部 **【开始 (Home)】** 选项卡最右侧即可看到 **【AI 创作助手】** 按钮组；或者在 **【插入】** → **【我的加载项】**（或 **【外接程序】**）→ **【开发人员】** 中添加启动。

---

### 方案 B：Word 网页版 (Office for the Web)

1. 打开微软官方 [Word 网页版](https://word.office.com/) 并新建一篇文档。
2. 点击顶部菜单栏的 **【插入 (Insert)】** → **【加载项 (Add-ins)】**。
3. 在弹出窗口中选择 **【我的加载项 (My Add-ins)】** → **【上传我的加载项 (Upload My Add-in)】**。
4. 选中本项目根目录下的 `manifest.xml` 文件并确认上传。
5. 成功后，顶部选项卡将显示插件图标，点击即可在侧边栏唤起！

---

## ⚙️ 模型配置与快速上手

1. 在 Word 侧边栏中点击右上角 **⚙️【设置】** 图标。
2. **选择服务商**（例如 **DeepSeek**，系统将自动填充 Base URL 与默认模型）。
3. **输入 API Key**（在对应平台申请的 Key，如 `sk-...`）。
4. （可选）点击 **【获取/刷新模型】** 按钮从服务端动态加载可用模型列表并选择。
5. 点击 **【测试 API 连通性】**，提示成功后点击 **【保存并应用】**。

## 💡 常见操作技巧

1. **选中即处理**：在 Word 文档中划选文字，侧边栏会自动显示选中内容，直接点击“润色优化”、“论文降重”等快捷按钮即可。
2. **自选常用指令**：点击自定义指令输入框下方的 **“管理”** 链接打开抽屉，勾选/取消勾选 **“快捷显示”**，即可根据个人习惯定制主界面上的快捷按钮。
3. **即时热更新**：若插件有更新或代码修改，在插件侧边栏空白处右键点击，选择 **“重新加载 (Reload)”** 即可立即加载最新版本，无需重启 Word。
4. **完全卸载**：若不再需要本插件，双击运行 `uninstall-from-word.bat` 即可一键清除注册表配置及本地共享。
