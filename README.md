# Word AI 创作助手 (Word AI Copilot Add-in)

基于微软现代官方 **Office Web Add-in** 规范与 **Word.js API** 开发的高性能 AI 创作助手插件，无缝嵌入 Microsoft Word 侧边栏，支持对文档中的文字进行智能润色、扩写、纠错、翻译、自由对话创作，并提供一键写回替换、追加与 Diff 对比功能。

---

## ✨ 核心特性

- **文档选区实时感知**：自动抓取 Word 中选中的文字段落，显示字数统计与即时预览。
- **一键快捷 AI 动作**：
  - ✨ **润色优化**：修正生硬表达，提升文采与语意连贯性。
  - 📝 **扩写充实**：扩展论证细节、案例说明与逻辑支撑。
  - 💡 **提炼精简**：快速抽取长文或段落核心观点，形成要点总结。
  - 🔍 **语法纠错**：精准识别错别字、标点误用与病句。
  - 💼 **商务公文**：将口语化内容转换为规范得体的职场公文。
  - 🎓 **学术规范**：转换为客观、严谨的学术论文论述风格。
  - 🌐 **双语翻译**：高质量中英互译（信达雅母语级表达）。
- **自由 Prompt 创作**：在侧边栏直接输入任意自定义需求，支持快捷键 `Ctrl + Enter` 执行。
- **灵活文档写回机制**：
  - **替换选中**：直接用 AI 生成的内容覆盖文档当前选中文字。
  - **在后方追加**：在选中文本后面无缝插入新段落。
  - **光标处插入**：直接输出到文档光标所在位置。
  - **复制结果**：一键拷贝到剪贴板。
  - **Diff 对比**：并排对比修改前后的内容差异。
- **多模型通用接口**：完全兼容 OpenAI 接口规范，内置 **DeepSeek (推荐)**、**OpenAI (GPT-4o)**、**硅基流动**、**Moonshot (Kimi)** 以及 **本地 Ollama** 等服务商一键切换。
- **纯本地安全存储**：API Key 仅保存在本机浏览器沙箱（localStorage）中，不经过任何第三方中转，安全可控。

## 🚀 快速上手：三步运行插件

### 第一步：启动本地服务

Office 插件要求侧边栏页面运行在安全协议下（`https://localhost:3000`）。项目中已内置自动签名和服务器脚本：

1. **Windows 环境**：直接双击运行 `start.bat`。
2. **或者在命令行中运行**：
   ```bash
   python server.py
   ```
3. 启动后，控制台会输出：
   ```text
   🚀 Word AI Copilot Add-in 本地调试服务已就绪！
      访问地址: https://localhost:3000/src/taskpane.html
      清单文件: manifest.xml
   ```
4. **信任本地证书（重要）**：
   在浏览器中打开 `https://localhost:3000/src/taskpane.html`。如果浏览器提示“您的连接不是私密连接/不安全”，请点击【高级】→【继续前往 localhost】。完成该步骤后，Word 内部的 WebView 才能正常加载本地页面。

---

### 第二步：在 Microsoft Word 中加载插件（侧载 Sideloading）

你可以选择 **桌面版 Word** 或 **网页版 Word** 加载本插件：

#### 方案 A：在 Word 网页版中加载（最快、最简便）
1. 访问微软官方 [Word 网页版 (Office for the Web)](https://word.office.com/) 并新建一篇文档。
2. 点击顶部菜单栏的 **【插入 (Insert)】** → **【加载项 (Add-ins)】**（若折叠，在三个点 `...` 中）。
3. 在弹出的窗口中选择 **【我的加载项 (My Add-ins)】** → **【上传我的加载项 (Upload My Add-in)】**。
4. 点击“浏览”，选中本项目根目录下的 `manifest.xml` 文件并确认。
5. 成功后，Word 顶部【主页】选项卡最右侧会出现 **【AI 智能创作】** 按钮组，点击即可唤起侧边栏！

#### 方案 B：在 Windows 桌面端 Word 中加载（一键自动安装 ⚡ 推荐）
1. 在项目文件夹中，直接双击运行 **`install-to-word.bat`**。
2. 脚本会自动将当前插件注册到 Office 的 Web 扩展开发者注册表（`WEF\Developer`），并清理旧缓存。
3. 打开桌面端 Microsoft Word（若已打开，请先完全退出后重新启动）。
4. 点击顶部功能区 **【插入】** → **【我的加载项】**（或 **【外接程序】**）。
5. 在 **【开发人员加载项】**（或 **【共享文件夹】**）中即可看到 **【Word AI 创作助手】**，点击添加即可！
   *(注：部分较新版本的 Office 365 甚至会自动直接将按钮加载到【开始】功能区最右侧)*

#### 方案 C：在 Windows 桌面端 Word 中手动加载（备用方案）
1. 在电脑上新建一个专用文件夹（例如 `D:\OfficeAddins`），将本项目的 `manifest.xml` 复制进去。
2. 右键该文件夹 → **【属性】** → **【共享】** 标签页 → 点击 **【共享(S)...】**，添加你的当前用户为“读取”权限，完成共享。
3. 复制生成的网络路径（格式如：`\\计算机名\OfficeAddins`）。
4. 打开桌面端 Microsoft Word，点击左上角 **【文件】** → **【选项】** → **【信任中心】** → **【信任中心设置...】**。
5. 选择 **【受信任的加载项目录】**：
   - 在“目录 URL”中粘贴刚刚复制的网络路径（`\\计算机名\OfficeAddins`）。
   - 点击 **【添加目录】**，并勾选 **【在菜单中显示】**。
   - 点击“确定”保存并重启 Word。
6. 重启 Word 后，点击 **【插入】** 选项卡 → **【我的加载项】** → 切换到 **【共享文件夹】**，即可看到 `Word AI 创作助手`，点击添加即可！

---

### 第三步：配置 AI 接口（以 DeepSeek 为例）

1. 在 Word 中点击右侧面板右上角的 **⚙️【设置】** 图标。
2. 服务商选择 **DeepSeek**（系统会自动填充 `https://api.deepseek.com/v1` 和 `deepseek-chat`）。
3. 填入你在 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请的 API Key（格式为 `sk-...`）。
4. 点击 **【测试 API 连通性】**，若提示 `✅ 连接成功！`，说明配置完全正常。
5. 点击 **【保存并应用】**。

## 🎯 使用指南

### 1. 处理选中文本
- 在文档正文中用鼠标划选一段文字。
- 侧边栏顶部的“当前文档选中内容”卡片会自动同步选中文本和字数。
- 点击任意快捷动作（如 **✨润色优化** 或 **💡提炼精简**），AI 将实时流式输出结果。

### 2. 将结果写回 Word
AI 生成完毕后，面板底部提供便捷的写回工具条：
- 点击 **【替换选中】**：文档中高亮的原文字将被 AI 润色后的版本直接取代。
- 点击 **【在后方追加】**：原文字保留，新段落自动插入在原文字后方。
- 点击 **【光标处插入】**：在当前光标定位处写入内容。
- 点击 **【查看与原文对比 (Diff)】**：可并排查看修改前与修改后的文字差别。

### 3. 自由提问与续写
- 在“自定义指令 / 对话生成”输入框中输入任何个性化提示词（例如：“将这段文字改写为小红书文风，带 3 个 emoji”）。
- 可勾选/取消勾选“引用选中文本”。
- 按 `Ctrl + Enter` 或点击“执行”，即可获得精准输出。

## 🛠️ 常见问题 (FAQ)

### Q1: 侧边栏打开后显示白屏或提示证书错误？
**A:** 请确认 `server.py` 已经运行，并先用 Chrome 或 Edge 浏览器手动打开 `https://localhost:3000/src/taskpane.html`，点击高级并信任自签名证书。此后 Word 即可正常加载。

### Q2: 能否使用本地大模型（如 Ollama）？
**A:** 完全支持！确保本地已启动 Ollama 服务，在插件设置中选择【本地 Ollama】，Base URL 填写 `http://localhost:11434/v1`，Model 填写你的本地模型名（如 `qwen2.5:7b` 或 `llama3:8b`），API Key 随意填写字符即可。

### Q3: 如何将插件部署到正式生产环境？
**A:** 若需要团队多台电脑使用，只需将 `src` 和 `assets` 目录下的静态网页上传至任意支持 HTTPS 的 Web 服务器（如 Nginx、Vercel、Cloudflare Pages 或内网服务器），然后将 `manifest.xml` 中的所有 `https://localhost:3000` 批量替换为你正式服务器的域名 URL，再通过 Microsoft 365 管理员中心统一分发即可。
